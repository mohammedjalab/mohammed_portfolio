# Mohammed Deeb Jalab — Portfolio

My personal portfolio website, built with **Dart** and **[Jaspr](https://jaspr.site/)**.

The website showcases my projects, technical skills, experience, and services as a software developer.

**Live Website:** [mohammedjalab.github.io/mohammed_portfolio](https://mohammedjalab.github.io/mohammed_portfolio/)

## Tech Stack

- **Language:** Dart
- **Framework:** Jaspr
- **Styling:** CSS
- **Hosting:** GitHub Pages
- **Deployment:** GitHub Actions

## Features

- Responsive portfolio layout
- Projects showcase
- Skills and experience sections
- Services and contact information
- Reusable Jaspr components
- Static site generation

## Getting Started

### Prerequisites

- Dart SDK
- Jaspr CLI

### Installation

Clone the repository:

```bash
git clone https://github.com/mohammedjalab/mohammed_portfolio.git
cd mohammed_portfolio
```

Install dependencies:

```bash
dart pub get
```

Install the Jaspr CLI:

```bash
dart pub global activate jaspr_cli
```

### Build

Generate the static website:

```bash
jaspr build
```

The generated website is available in:

```text
build/jaspr/
```

## Deployment

The website is hosted on GitHub Pages.

GitHub Actions automatically builds and deploys the website whenever changes are pushed to the `main` branch.
